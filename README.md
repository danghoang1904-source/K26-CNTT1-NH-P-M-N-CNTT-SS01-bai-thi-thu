 Website Văn Phòng Phẩm

Website **bán hàng** của cửa hàng *văn phòng phẩm*.

| Thư mục | Nội dung |
|---------|----------|
| docs | file nhap_hang.txt - danh sách hàng cần nhập thêm |
| media | logo cửa hàng |
| data | file Excel đơn bán tháng 10 |
| logs | file 'shop.log' và các báo cáo lọc được |
| backup | bản sao logo dự phòng |

Lệnh liệt kê toàn bộ dự án (kể cả file ẩn):

```shell
ls -aR
```

- [x] Sắp xếp lại thư mục và đổi tên file thành snake_case
- [x] Lọc log và tạo các file báo cáo
- [ ] Đưa website lên hosting

> Chú ý: file `.env` chứa thông tin bảo mật, tuyệt đối **không upload** lên GitHub.
